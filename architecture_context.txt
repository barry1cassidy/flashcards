What the product is
Personal flashcard app: create decks, study with Flip / Quiz / Write, SM-2 spaced repetition. Cards have front, back, optional hint. Decks have front/back TTS languages. Users organize decks into Sets (UI term). Internally/API they are still groups (/api/groups, table deck_groups, pages GroupsPage / GroupDetailPage). Frontend routes are /sets with redirects from /groups. There is also a shared Library of language phrasebooks. i18n is English + Spanish (frontend/src/i18n/locales/). Settings: appearance Light/Dark, UI language, deck sort. New accounts default DARK.

Backend architecture
Package root com.flashcards. Controllers under /api/*, JWT auth except login/register/google. Jackson 3 uses tools.jackson.databind (not com.fasterxml.jackson).

Main surfaces:

/api/auth — register, login, Google, GET/PATCH /me
/api/decks + /api/decks/{id}/cards — CRUD
/api/groups — personal sets
/api/decks/{id}/study and POST /api/cards/{id}/review — SM-2. card_reviews is 1:1 with card_id, so two users cannot share the same card row for progress.
/api/decks/{id}/import and /export — CSV front,back,hint
/api/library — shared catalog (authenticated)
Library is separate tables on purpose (library_groups, library_decks, library_cards), not null-user_id rows in personal tables. Catalog is shared, read-only, attributed. Studying copies into the user’s decks so SM-2 stays per-user. POST /api/library/decks/{id}/add is idempotent (uk_decks_user_library). Copy lands in a personal set named after the language (find by name case-insensitive, else create). decks.library_deck_id points at the catalog deck.

Library content: where it came from
Not a Flyway data migration.

Source: English Wikivoyage phrasebooks, CC BY-SA 4.0. Do not copy Duolingo/Anki/Say It Travel. Attribution is stored per language and shown on library group pages.
Ingest (offline): backend/scripts/ingest-wikivoyage-library.mjs hits the MediaWiki API (needs a User-Agent; retries/delay for 429s) and writes backend/src/main/resources/library/phrasebooks.json. Optional: node scripts/ingest-wikivoyage-library.mjs chinese to merge one language. Seed throws if a language produces 0 decks.
Runtime seed: LibrarySeed (ApplicationRunner) loads that JSON only if library_groups is empty. If tables are half-seeded, wipe library tables or skip — it will not refresh in place.
Catalog shape: 20 languages as library “groups” (Spanish, French, German, Italian, Portuguese, Chinese (Mandarin), Japanese, Korean, Arabic, Russian, Hindi, Turkish, Dutch, Polish, Swedish, Greek, Vietnamese, Thai, Indonesian, Hebrew). Same 10 decks each where Wikivoyage had enough phrases: Greetings & courtesy, Survival phrases, Numbers, Time & dates, Getting around, Somewhere to stay, Money, Eating out, Shopping, Help & emergencies (~20 cards). Some languages are thinner (Hindi/Hebrew/etc.).
Mandarin: characters on card back, pinyin as hint (e.g. front Hello. / back 你好。 / hint Nǐ hǎo). Logic in the ingest parser for zh-CN.
