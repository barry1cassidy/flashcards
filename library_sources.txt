Language library sources
Search for a shared, not-user-owned phrase library: English into about 20 languages, the same 10 units everywhere, licensed for reuse. Compared Wikivoyage, Tatoeba, LibreLingo, FSI/Peace Corps, Speak phrasebook, and commercial apps. Recommendation below; open this canvas beside the chat to keep the catalog while we implement.

Recommended source: Wikivoyage phrasebooks
English Wikivoyage publishes a shared phrasebook template (Basics, Problems, Numbers, Time, Transportation, Lodging, Money, Eating, Shopping, and more) used across languages. Spanish and Mandarin pages both follow it. License is CC BY-SA 4.0: we can ship a library if we attribute the article and keep derivatives under the same license. Fetch via the public MediaWiki API (en.wikivoyage.org), not by scraping a commercial app.

Catalog shape
One library group per language, ten identical decks inside each group. Search should hit both, so “Spanish greetings” and “Eating out Japanese” both work. Group names drop “Language Basics” — the library already means beginner phrases, and the language name is what people type.

Decks (same 10 in every group)
Names follow traveler situations, not “Unit 1”. Wikivoyage’s Bars, Driving, Colors, and Authority sections are skipped or folded in so we stay at ten decks of about twenty cards. There is no separate “business travel” list in the source; Money + Getting around + Help cover that need without inventing a unit that would drift by language.

How this maps to the app
Library vs My decks
This content is not owned by a user. Add a left-menu item such as Library (alongside My decks). Opening it lists the 20 language groups. Search on that screen filters groups and decks: “Spanish”, “greetings”, “Chinese eating”.

A library deck can later be copied into the user’s own decks if they want to edit or mix cards. The canonical set stays shared. Attribution for Wikivoyage belongs on the library deck (link to the phrasebook page and CC BY-SA 4.0), not on the user’s private copy unless we keep serving the same text.

Public API: en.wikivoyage.org/w/api.php. Reuse rules: How to re-use Wikivoyage guides.

Do not copy
Duolingo, Babbel, Memrise, Anki shared decks, and sites like Say It Travel are the wrong shape legally even when the phrases look similar. Short everyday sentences are common, but their collections, order, and wording are not a free dataset. Wikivoyage is the one that is both themed and explicitly licensed for this.
